# SecureTrack — Android Setup & Build Guide

This document details prerequisites, environment setup, build instructions, and device deployment for the SecureTrack Android client.

---

## 1. System Requirements

- **Operating System**: Windows 10/11, macOS 12+, or Linux Ubuntu 22.04+
- **JDK**: Java Development Kit 17 (Eclipse Temurin 17 or OpenJDK 17 recommended)
- **IDE**: Android Studio Ladybug (2024.2.1) or newer
- **Android SDK**:
  - `compileSdk`: 35 (Android 15)
  - `minSdk`: 26 (Android 8.0 Oreo)
  - `targetSdk`: 35 (Android 15)
- **Build Tools**: 35.0.0

---

## 2. Key Dependencies & Libraries

- **Architecture**: Java + XML, Material Components 3
- **Google Play Services**: Location (`play-services-location:21.3.0`), Maps (`play-services-maps:19.0.0`)
- **Firebase BoM**: `firebase-bom:33.7.0` (Auth, Firestore, Analytics)
- **Barcode / QR Scanning**: ZXing Android Embedded (`zxing-android-embedded:4.3.0`)
- **Networking**: Retrofit 2 + Gson (Legacy backend reference integration)

---

## 3. Building the Android Application

Open a terminal in the root directory:

```bash
# Clean the project
./gradlew clean

# Run local unit tests
./gradlew testDebugUnitTest

# Assemble the debug APK
./gradlew assembleDebug
```

The compiled APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

---

## 4. Deploying to a Physical Device / Emulator

### Prerequisites:
1. Enable **Developer Options** and **USB Debugging** on the target Android device.
2. Connect the phone via USB and authorize the computer's ADB fingerprint.

### Command Line Installation:
```bash
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Launching the Application:
```bash
adb shell am start -n com.example.securetrack/.ui.SplashActivity
```

---

## 5. Required Runtime Permissions

SecureTrack relies on specific Android system capabilities to provide anti-theft and tracking protection:

1. **Location**:
   - `ACCESS_FINE_LOCATION` and `ACCESS_COARSE_LOCATION`
   - `ACCESS_BACKGROUND_LOCATION` (enables continuous tracking when screen is locked)
2. **Foreground Service**:
   - `FOREGROUND_SERVICE` and `FOREGROUND_SERVICE_LOCATION` (prevents OS termination during active tracking)
3. **Camera**:
   - `CAMERA` (used to scan pairing QR codes generated by the web dashboard)
4. **Device Administration**:
   - `DevicePolicyManager` permission (`SecureAdminReceiver`), allowing remote lock and security policies.
5. **Notifications**:
   - `POST_NOTIFICATIONS` (Android 13+ status bar notifications)
